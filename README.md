# Expense Tracker

A responsive Expense Tracker application built with React and Vite.

## Features

- Add expenses
- Edit expenses
- Delete expenses
- Search expenses
- Filter expenses by category
- Track total expenses
- Expense date management
- Loading and error states
- Responsive design

## React Concepts Used

- useState
- useEffect
- useRef
- useMemo
- Props
- Callback functions
- Conditional rendering

## Tech Stack

- React
- Vite
- JavaScript
- HTML
- CSS
- Bootstrap
- Mock API
